# Synthetic microbiome manuscript excerpt

## Methods

Samples were collected at three coastal sites with recorded latitude and longitude.

DNA libraries were sequenced on an Illumina instrument with paired-end reads.

Taxonomic profiles were generated using Kraken2 and a named reference database.

Group differences were assessed using permutation tests with false discovery rate correction.

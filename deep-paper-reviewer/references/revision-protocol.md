# Evidence-Constrained Revision Protocol

## Constraint Map

Translate each user request or review concern into a rule with:

- scope;
- required evidence;
- permitted edits;
- forbidden interpretation;
- verification test.

Resolve conflicts by applying the newest explicit user instruction and reporting the conflict.

## Surgical Editing

1. Preserve the authoritative source.
2. Inventory figures, citation fields, comments, styles, and custom XML before editing DOCX.
3. Edit only paragraphs traceable to the constraint map.
4. Mark changed text as requested; do not mark untouched text.
5. Preserve all numbers unless verified against their generating data.
6. Do not add literature until the source and claim fit are verified.
7. Reconcile in-text citations with the reference list.
8. Recheck figure, SI, table, and dataset numbering after every move.

## Cross-Check

- Search for residual causal verbs and inflated modifiers.
- Confirm latitude remains a correlate unless causal identification exists.
- Confirm functional overlap is not treated as functional equivalence or redundancy without functional measurements.
- Confirm ASV, lineage, read-based, MAG, transcript, and rate evidence are not conflated.
- Confirm gene absence is cautious and gene presence remains potential.
- Confirm Results contain observations rather than literature-supported mechanistic discussion.
- Run a fresh reviewer pass without relying on the original review summary.

## Stop Conditions

Stop and report rather than guess when the authoritative version is unclear, a requested value conflicts with source data, a citation cannot be verified, or a structural rewrite would exceed the permitted scope.
